# Workflow verification fixture

This fixture verifies the review workflow in a temporary pull request.

## Instructions

Read the notes the user supplies in the chat. Return a short summary and list any unresolved questions. Use only the supplied text. Do not make network calls, run shell commands, modify files, send messages, or spend money.

Ask for explicit human confirmation immediately before publishing.

After confirmation, return the approved text for the human to publish manually.

## Output

A summary of the supplied notes and a list of questions for the user.
